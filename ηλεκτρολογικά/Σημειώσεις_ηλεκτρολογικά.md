# Ηλεκτρολογικά – σημειώσεις (φάκελος ανοίχτηκε 03/11/2026, χωρίς τεύχος ακόμη)

Δεν έχει γίνει ακόμη ηλεκτρολογικό σχέδιο. Στοιχεία που υπάρχουν ήδη σε άλλους φακέλους και θα χρειαστούν:
- Φωτισμός / spots / παροχές οροφής / ανιχνευτές του Β1: φάκελος **ανόψεις** (R02–R06: 25 spots, ΚΡΕΜ0 καθιστικό, ΚΡΕΜ1 τραπεζαρία, LED3 κεφαλάρι, ΑΚ1–ΑΚ4 + ΑΘ5, κυκλώματα α–ν, χωρίς μηχανικό εξαερισμό λουτρών, 1 access point).
- Σύσταση ΟΙ (00_ΓΕΝΙΚΑ): εκκρεμεί πρόβλεψη για φορτιστές EV / καλώδια από πίνακες διαμερισμάτων σε θέσεις & αποθήκες – να ληφθεί υπόψη στο ηλεκτρολογικό.
- Κανόνας έργου: καμία οπή σε δοκό· κολόνες (σκούρο γκρι) δεν αγγίζονται· οδεύσεις σε γεμίσματα δαπέδων / ψευδοροφές / τοίχους Τ2–Τ3.

Εκκρεμεί: οδηγίες Γιάννη για πίνακες, πρίζες, διακόπτες, ασθενή, θέση μετρητών, φορτιστές EV.
