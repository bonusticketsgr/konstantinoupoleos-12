## Τοιχοποιίες Β1 – νέος γεννήτορας (cloud, 05/11/2026)

| `b1_model.py` | μοντέλο Β1: είδη τοιχοποιιών, αλλαγές R15 πάνω στο R14, ντουλάπες, λουτρά, πόρτες, αλυσίδες διαστάσεων, σημειώσεις |

| `draw.py` | βοηθητικά ReportLab (A3, κλίμακα, διαγράμμιση, ετικέτες, αλυσίδες, πόρτες, υπόμνημα) |
