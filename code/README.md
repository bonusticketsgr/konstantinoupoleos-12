## Τοιχοποιίες Β1 – νέος γεννήτορας (cloud, 05/11/2026)
`toixopoiies/` – Python (PyMuPDF για ανάγνωση, ReportLab για σχεδίαση, γραμματοσειρές Inter στο `fonts/`):

| Αρχείο | Ρόλος |
|---|---|
| `extract_r14.py` → `data/b1_geom_r14.json` | ανάκτηση γεωμετρίας (τοίχοι, κολόνες, κουφώματα, ETICS, έπιπλα, κείμενα) από το διανυσματικό PDF του R14 σε συντεταγμένες μοντέλου (m) |
| `b1_model.py` | μοντέλο Β1: είδη τοιχοποιιών, αλλαγές R15 πάνω στο R14, ντουλάπες, λουτρά, πόρτες, αλυσίδες διαστάσεων, σημειώσεις |
| `quantities.py` | προμέτρηση ανά είδος + λίστα παραγγελίας (παραδοχές Τ-03) |
| `draw.py` | βοηθητικά ReportLab (A3, κλίμακα, διαγράμμιση, ετικέτες, αλυσίδες, πόρτες, υπόμνημα) |
| `sheet_t01.py` · `sheet_t02.py` · `sheet_t03.py` | τα φύλλα που τυπώνονται: Τ-01 κάτοψη · Τ-02 είδη · Τ-03 απλή προμέτρηση (m² ανά τύπο + ETICS 10/5) |
| `sheet_t01a.py` · `sheet_t03_detailed.py` | ΔΕΝ τυπώνονται (ο Γιάννης δεν τα θέλει, 05/11): φύλλο χάραξης με πίνακα παρειών · αναλυτική λίστα υλικών |
| `build_b1tx.py` | `python3 build_b1tx.py` → `ΚΩΝΣΤΑΝΤΙΝΟΥΠΟΛΕΩΣ_12_ΑΡΓΥΡΟΥΠΟΛΗ/ΤΟΙΧΟΠΟΙΙΕΣ/Β1_ΤΟΙΧΟΠΟΙΙΕΣ_Τ-01_Τ-03_<REV>.pdf` |

Εξαρτήσεις: `pip install pymupdf shapely reportlab`. Τρέχουσα έκδοση R20 (05/11/2026). **Ισόγειο**: `gf_model.py` (μοντέλο γραμμένο ρητά, ίδιο σύστημα συντεταγμένων) → `python3 build_gftx.py` → `ΙΣΟΓΕΙΟ_ΤΟΙΧΟΠΟΙΙΕΣ_Τ-01_Τ-04_<REV>.pdf` (τρέχουσα R06, 06/11/2026 – βάση A-10-GF R01 05/11/2026· WC 1,30×1,00 στη ΒΑ γωνία της ζώνης καθιστικού-κουζίνας (θέση αρχιτέκτονα) με ψυγείο 0,80 στην εσοχή δίπλα του, βόρειος τοίχος καθιστικού στο 5,05–5,15 (σαλόνι 3,975), κουζίνα στον Τ6-01 + νησίδα-χερσόνησος 0,90×1,80 με διάδρομο 1,10 και 3 θέσεις, καναπές 2,70 από το μοντέλο, σαλόνι 4,75×3,975 χωρίς όγκους, Τ6-01 στο 9,55–9,70 περασιά με τα υποστυλώματα του lobby, είσοδος κτιρίου Θ0.04 1,20 + W0.04 1,25, Υπν.1 ντουλάπες 5,1 m, χωλ 0,90, Τ3 CW 30 περασιά με Τ9 όπως Β1, είσοδος κτιρίου στον νότιο τοίχο του lobby, Τ-04 περιβάλλων χώρος 1:100)· έπιπλα EPIPLA: `python3 -I extract_gf_furn.py <A-10-GF.pdf> data/gf_furn.json` (πεδίο `FURN_PATHS`, `draw_furn()`)· περιβάλλων χώρος: `python3 -I extract_gf_site.py <A-10-GF.pdf> data/gf_site.json` (διανυσματική γεωμετρία A-10-GF χωρίς κείμενα/διαστάσεις, πεδίο `SITE` του μοντέλου, `draw_site()` στο sheet_t01.py, clip έξω από το πολύγωνο `BUILDING`)· τα sheet_t0x.py / quantities.py διαβάζουν προαιρετικά πεδία του μοντέλου (SHEET, LEGEND, FURN, FURN_PATHS (+ `shift`: μετατόπιση ομάδων επίπλων), EQUIP (κουζίνα / νησίδα / κρεβάτι: rect·tall·appl·hob·sink·bed·seat·sofa – `equip()`), CIRCLES, EXTRA_TEXTS, SITE, FRAMES, TYPES, OX/OY, WIN_SIZES, BATH_SIDES, LINTELS, PLAN_*) με προεπιλογές Β1. **Έλεγχος γωνιών πριν από κάθε παραδοτέο**: `python3 check_corners.py gf|b1` (raster 1 cm των τοίχων/υποστυλωμάτων – κλειστές τρύπες και σημειακές επαφές τοίχων = «λευκές κουκίδες» στο PDF· πρέπει 0/0). `extract_gf.py` → `data/gf_geom.json` (γεωμετρία A-10-GF σε m μοντέλου). Νέα έκδοση: άλλαξε `REV`/`DATE` στο `b1_model.py`, κάνε τις αλλαγές στο μοντέλο, τρέξε `build_b1tx.py`, μετακίνησε το παλιό PDF στο `παλαιότερες_εκδόσεις/`.
