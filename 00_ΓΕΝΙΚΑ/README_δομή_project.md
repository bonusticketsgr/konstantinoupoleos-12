## Κοινοί κανόνες
- Συντεταγμένες μοντέλου: m, x → ανατολή, y → νότος, αρχή = εξωτ. Β παρειά Τ4-01 / εξωτ. Δ παρειά Τ4-05.
- Ύψη: ισόγειο 3,00 · όροφοι 2,90 · σοφίτα 2,65 · υπόγειο 2,80. Πλάκα οροφής Β΄ +9,85.
- Σκούρο γκρι = κολόνες/τοιχεία (δεν αγγίζονται) · ανοιχτό γκρι = τοιχοποιίες. Καμία οπή σε δοκό.
- Τοιχοποιίες: Τ1 τούβλο 25 + Τ3 από μέσα · τοίχος λεκάνης παντού CW50 + διπλή γυψοσανίδα + κενό 12 + CW30 + διπλή γυψοσανίδα · **όπου πλακάκι ή ντουλάπα, χωρίς γυψοσανίδα (τούβλο ή μπετό)** · κολώνες μία κολλητή γυψοσανίδα, περασιά.
- Επίπλωση από το layer EPIPLA του αρχιτέκτονα· σχέδια τοιχοποιιών χωρίς έπιπλα, χωρίς υδρορροές.
- Σχέδια: μεγάλα γράμματα, Α3, ελληνικά· κάθε θέμα σε δικό του φάκελο.
