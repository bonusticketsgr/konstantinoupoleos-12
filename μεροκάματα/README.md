# Μεροκάματα εργοταξίου – Κωνσταντινουπόλεως 12

Καθημερινή καταγραφή πόσα άτομα δούλεψαν στην οικοδομή, ανά συνεργείο.

- Ένα αρχείο ανά μήνα: `YYYY-MM.csv` (ημερομηνία;συνεργείο;άτομα;σημείωση).
- `τιμές.json` (προαιρετικό): €/μεροκάματο ανά συνεργείο, π.χ. `{"καλούπια": 70, "σιδεράδες": 80}` – αν υπάρχει, το μηνιαίο σύνολο βγαίνει και σε €.
- Script: `python3 code/merokamata/merokamata.py` (add / show / month / year).

Ροή: κάθε πρωί στις 8 ο Claude ρωτά τον Γιάννη «πόσα άτομα δουλεύουν σήμερα;», καταχωρεί την απάντηση (π.χ. «5 καλούπια, 3 σιδεράδες»), και στο τέλος κάθε μήνα δίνει το σύνολο μεροκάματων ανά συνεργείο.
